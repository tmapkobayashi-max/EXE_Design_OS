# 提案スライドの品質目標

参照：<https://codex-deck-benefits-v2.vercel.app/>

目指すのは、情報をカードに整理しただけの資料ではない。1枚ずつに明快な主張があり、
大きなビジュアルと少ない言葉で、読み手が次のページへ進みたくなる提案資料である。

## Codexが完結する範囲

1. 素材から事実・論点・未確定事項を分ける
2. 提案の結論とスライド構成をつくる
3. スライドごとの図解、SVG、必要な画像を制作する
4. 1920 x 1080 のHTMLデッキとして実装する
5. 全スライドを画像化し、密度・可読性・破綻を確認して修正する

人が担うのは、顧客情報の提供、事実の最終確認、対外送付の承認だけとする。

## 合格の見た目

- 初見で、そのページの主張を3秒以内に言い直せる
- 図や情景が画面の主役で、文章はそれを補助している
- どのページにも、そのページ固有の構図・図解・視覚的な理由がある
- 余白は意図的で、単に要素が小さいために空いていない
- 通しで見たとき、話の熱量と視覚密度が落ちない
