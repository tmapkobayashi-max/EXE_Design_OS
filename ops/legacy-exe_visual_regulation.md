# EXE提案スライド・デザインシステム＆マスターガイド (Final Version v3.1)

## 1. ブランド・アイデンティティ & カラー定義
*   **コア・モットー:** 「システムでできることは『システム』で！」
*   **企業理念:** 「必殺技を作ること」— 困りごとをボタン一つで解決するIT技術の提供
*   **ブランドカラー (HEXコード厳守):**
    *   **Main Pink:** `#FF6366`（自社の強み、解決策、強調数字、自社フロー）
    *   **Sub Grey:** `#D6E4E7`（現状課題、従来手法、他社比較、補足）
    *   **Base Black:** `#1E1C1C`（メインテキスト、ロゴ）
    *   **Accent Yellow:** `#F8E700`（限定的なアクセント）

## 2. 共通レイアウト・数値定義 (Global Layout Rules)
*   **スライド背景:** **純白 (#FFFFFF) で統一**。グラデーションや装飾的な背景は一切禁止。
*   **ノンブル (ページ番号):** **スライド上部中央に固定**。
    *   **表記ルール:** **「1」「2」といった算用数字のみ**を記載すること。「Number:」や「Page:」「[Nombre: X]」といった**ラベルや記号は一切含めない**（テンプレート流し込み時のズレを防止するため）。
    *   **スタイル:** サイズ最小（Level 4相当）、色は Sub Grey (#D6E4E7)。
*   **フォント:** ブランドキットで指定したEXE指定フォントを100%適用。
*   **テキスト制約:** 1ブロック **2〜3行以内**。4行以上は「縦並び」等へレイアウト変更。
*   **フォント階層 (Kankyu Hierarchy):**
    *   **Level 1 (最優先):** 実績数字など。ページ内で最大サイズ（本文の3倍以上）を適用し、一目で強みが伝わるようにする。
    *   **Level 2 (タイトル):** スライド上部固定の中見出し。
    *   **Level 3 (本文):** 説明テキスト（2〜3行以内）。
*   **ファイル命名規則:** `YYYYMMDD_顧客名_案件名_EXE提案書.pdf`

## 3. デザイナブル・ビジュアル・ルール
AIがCanva等で「プロの仕上がり」を再現するための具体的なビジュアル指示です。
*   **ホワイトスペース (余白):** スライドの上下左右に **「40px以上」** の十分な余白を確保し、中央に要素を凝縮させる。
*   **図解とテキストの比率:** 視覚要素（図解）**6** に対し、テキスト **4** の比率を維持し、情報の圧迫感を排除する。
*   **グラフィックスタイル:** アイコンは **「細めのラインアイコン」** を選択し、洗練されたロジカルな印象を与える。

## 4. コンポーネント・ライブラリ (UI Patterns)
*   **比較 (Contrast):** ビフォーアフター（中央太矢印）、項目比較（色や破線で対比）。
*   **構造 (Structure):** 3〜4工程は「横型」、項目が多い場合は「縦型」フローを選択。
*   **図解 (Graphics):** 項目3つ以下は「円型」、4つ以上は「四角型」を採用（四角は余白調整が容易なため）。
*   **特殊 (Specialized):** 相互関係（双方向矢印）、包括関係（入れ子構造）、ガントチャート（スケジュール）。

## 5. AI自律検証・出力仕様書 (Validation & Output)
AIは回答の最後に必ず以下の「出力仕様書」を付け、自らチェックを行うこと。

| 検証項目 | ルール内容 | AI確認 |
| :--- | :--- | :--- |
| **命名規則** | `YYYYMMDD_顧客名_案件名_EXE提案書` 形式か | ✅/❌ |
| **ノンブル表記** | 「Number:」等の余計な文字を排除し、**算用数字のみ**か | ✅/❌ |
| **配置固定** | 背景は白(#FFFFFF)か、ノンブルは上部中央か | ✅/❌ |
| **カラー論理** | 解決策は Pink(#FF6366)、課題は Grey(#D6E4E7)か | ✅/❌ |
| **テキスト量** | 全スライドで説明文が3行以内に収まっているか | ✅/❌ |
| **緩急の指定** | 実績数字をページ内最大サイズ（Level 1）に指定したか | ✅/❌ |
| **余白・比率** | 余白40px、図解：テキスト＝6:4の指示を含めたか | ✅/❌ |
