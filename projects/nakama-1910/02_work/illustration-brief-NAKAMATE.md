## ★Geminiに乗り換えるときの最重要ポイント

**必ず `01_cover.png` を添付して「この絵柄に完全に合わせてください」と伝えること。**

Gemini（Nano Banana）は**参照画像から絵柄を写すのが非常に得意**です。
文章で絵柄を説明するより、完成した1枚を見せるほうが圧倒的に揃います。

```
添付の画像と、まったく同じ絵柄・同じ色調・同じ線の太さで、
別の場面を1枚描いてください。絵柄は1ミリも変えないでください。

【構図】
（下記から1つコピー）
```

そのうえで、下の【スタイル】【NG】も併せて貼る。

Geminiは比率指定が効きにくいことがあります。**「16:9の横長」と明記**し、
それでも正方形で出たら「16:9の横長に描き直して」と続ける。

## 共通指定（構図の下に毎回貼る）

```
【スタイル】
・細い手描きの線画に、淡い水彩の陰影を乗せた絵柄
・彩度は低く、全体はグレーと生成り色（#F7F3EC に近い紙の色）を基調
・色を持つのは、光や窓明かりなど、ごく一部の #FF6366（サーモンピンク）だけ
・光源は1方向。強い影やグラデーションは付けない
・人物は表情を描き込まず、輪郭をシンプルに

【比率】
16:9の横長（1920×1080）

【厳守・NG】
・文字、数字、単語、ロゴ、記号を画像内に一切描かない
・グラフ、チャート、パネル、看板、モニター画面の中身を描かない
・写真的リアリズム、3DCG風の光沢を出さない
・指定した色以外の彩度の高い色を使わない
・指定した側は、文字を載せるため大きく空ける
```

# イラストを作らないスライド

図解が主役なので、絵は入れない。**全部が絵だと、かえって図が読めなくなる。**

| 枚 | 内容 | 扱い |
|---|---|---|
| 3 | 5つの体験の一覧 | 図解のみ。生成りの地に文字と図形 |
| 7 | 5機能の循環図 | 図解のみ |
| 9 | 応援の循環図 | 図解のみ |
| 11 | スケジュール | 図解のみ |
| 12 | 費用 | 文字のみ |

**絵のページと図のページを交互に置くとリズムが出ます。**
参照デッキも全ページが絵ではありません。

# 納品チェック

✓ 画像の中に文字・数字が入っていないか（**最も守られない**）
✓ `01_cover.png` と絵柄・色調が揃っているか（**Geminiに乗り換えたら特に注意**）
✓ ピンク以外の派手な色が入っていないか
✓ 16:9の横長になっているか
✓ 文字を載せる側が空いているか

NGなら**同じチャットで**「文字が入ったので消して」「もっと絵柄を添付画像に寄せて」と続ける。
作り直すより速い。

# 発注の順番（おすすめ）

絵柄が揃わなくなるリスクが高い順に、**先に難しいものから**。

```
1. ⑤ 10枚目（人が多く、いちばん難しい）
2. ③ 6枚目（動きがある）
3. ④ 8枚目（壁の展示）
4. ② 5枚目
5. ① 2枚目
6. ⑥ 13枚目（夜景・暗いトーン）
```

⑥だけトーンが違うので、**最後に単独で**頼むほうが他に影響しません。
