# EXE Design OS - 02 Visual System

Version: 1.1

---

# Purpose

The Visual System defines how every proposal should look.

Its purpose is not to create beautiful presentations.

Its purpose is to create presentations that are easy to understand, trustworthy, and consistent.

Every visual decision must support the philosophy defined in **01_PHILOSOPHY.md**.

---

# Visual Priority

When multiple design choices are possible, always follow this priority.

1. Clarity
2. Readability
3. Consistency
4. Brand Identity
5. Beauty

Never sacrifice understanding for visual impact.

---

# Background

Background Color

```
#FFFFFF
```

White is the default background for every slide.

White space is part of the design.

Empty space improves readability and creates trust.

Never use decorative backgrounds.

Never reduce readability using textures, gradients, or unnecessary effects.

---

# Color System

## EXE Pink

```
#FF6366
```

Purpose

- Solution
- Improvement
- EXE Strength
- Future
- Key Message
- Important Numbers
- Call To Action

Never use EXE Pink for problems or negative information.

---

## Sub Grey

```
#D6E4E7
```

Purpose

- Current Situation
- Problems
- Risks
- Conventional Methods
- Supporting Information

---

## Base Black

```
#1E1C1C
```

Purpose

- Titles
- Main Text
- Logo

---

## Accent Yellow

```
#F8E700
```

Purpose

- Small emphasis only

Never use Accent Yellow as a primary design color.

# Typography

Use the official EXE Font.

Hierarchy

Level 1

Major Numbers

Minimum three times body text size.

Level 2

Slide Titles

Level 3

Section Titles

Body Text

Maximum two to three lines.

Avoid long paragraphs.

---

# Layout System

Outer Margin

Minimum

```
40px
```

Content Ratio

Diagram

60%

Text

40%

Prefer visual explanation over written explanation.

Never create text-heavy slides.

---

# Spacing Matrix

| Element | Rule |
|----------|------|
| Outer Margin | 40px minimum |
| Section Gap | 32px |
| Card Gap | 24px |
| Icon and Text | 12px |
| Paragraph Gap | 16px |

Maintain consistent spacing throughout every slide.

---

# Grid Rules

Use a consistent grid.

Align every object.

Maintain equal spacing between related elements.

Never place elements arbitrarily.

Visual alignment is mandatory.

---

# Visual Hierarchy

Every slide communicates only one message.

One Slide

↓

One Message

If multiple unrelated ideas exist,

split them into multiple slides.

---

# Information Density

Default density is Medium.

Never exceed Medium.

When content exceeds available space,

create another slide.

Never reduce font size to fit more content.

---

# Diagram Rules

Choose diagrams before paragraphs whenever possible.

| Situation | Component |
|-----------|-----------|
| Comparison | Compare |
| Process | Flow |
| Timeline | Timeline |
| Schedule | Schedule |
| Metrics | Numbers |
| Multiple Features | Cards |
| Relationship | Relationship Diagram |
| Structure | Hierarchy Diagram |

Never invent a custom layout when an official component already exists.

---

# Icon Rules

Style

- Thin Line Icons
- Rounded Corners
- Minimal
- Simple

Recommended

Lucide Icons style

Avoid

- Heavy Icons
- Cartoon Icons
- Emoji
- Skeuomorphic Icons

Icons should support understanding.

Never use icons only for decoration.

---

# Image Priority

When selecting visuals, follow this order.

1. Diagram
2. Illustration
3. UI Screenshot
4. Product Image
5. Photography

Avoid decorative stock photos whenever possible.

Every image must improve understanding.

---

# Motion

Animation exists to support attention.

Never use animation for entertainment.

Allowed

- Fade In
- Slide Up
- Count Up
- Line Draw

Avoid

- Bounce
- Rotation
- Flash
- Zoom Explosion

---

# AI Decision Rules

When generating presentations,

always follow these rules.

If information can be visualized,

use a diagram.

If multiple layouts are possible,

choose the simplest.

If decoration conflicts with clarity,

remove decoration.

If multiple colors are possible,

follow the Color Decision Matrix.

Never invent new visual styles.

---

# Visual Anti-patterns

Never create slides with large text blocks.

Never use more than one accent color.

Never reduce white space to fit content.

Never mix illustration styles.

Never place icons without meaning.

Never add decorative shadows.

Never create layouts that reduce readability.

---

# Visual Checklist

Before generating the final presentation, verify:

✓ White background (#FFFFFF)

✓ Correct EXE Color usage

✓ Official EXE Font

✓ Minimum 40px margins

✓ One message per slide

✓ Diagram : Text = 6 : 4

✓ Thin Line Icons

✓ Text within two to three lines

✓ Correct visual hierarchy

✓ Consistent spacing

✓ Medium information density

✓ Minimal animation only

✓ No visual anti-patterns
