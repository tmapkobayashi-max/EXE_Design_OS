# イラスト発注書テンプレート

資料を1本つくるたびに、Codexがこの書式で発注書を出す。
人はこれをChatGPT（画像生成）にそのまま貼るだけでよい。

以下の `〈〉` を案件ごとに埋める。それ以外は変えない。

---

# 〈案件名〉 ― イラスト発注書

作成：〈YYYY-MM-DD〉
基準：`exe-design-os/docs/07_ART_DIRECTION.md`
発注先：ChatGPTの画像生成（**Codex／コード生成側では画像は作れない**）
原則：**1チャット1画像**

## 使い方

1. 下の「共通指定」をコピーしておく。
2. 各項目の「構図」を上に置き、その下に共通指定を貼って投げる。
3. 届いたPNGを `sozai/illust/` に、指定のファイル名で保存する。
4. ファイル名が揃ったら「画像が揃ったので差し込んで」と伝える。

★ **絵柄をそろえるコツ**：1枚目で気に入った絵ができたら、**同じチャットの続き**で
2枚目以降を頼む。チャットを分けると絵柄がズレる。

---

## 共通指定（★毎回そのまま貼る★）

```
【スタイル】
・細い手描きの線画に、淡い水彩の陰影を乗せた絵柄
・彩度は低く、全体はグレーと生成り色を基調にする
・色を持つのは「光る線・光る点」だけ。色は 〈#FF6366〉 のグロー
・光源は1方向のみ。強い影やグラデーションは付けない
・人物は表情を作り込まず、輪郭をシンプルに

【比率】
16:9

【厳守・NG要素】
・文字、数字、単語、ロゴ、記号を画像内に一切描かない
・グラフ、チャート、データパネル、ダッシュボード風の要素を描かない
・看板、タグ、プレート、モニター画面の中身のような矩形パネルも描かない
・写真的なリアリズム、3DCG風の光沢を出さない
・指定した色以外の彩度の高い色を使わない
・指定した側は、文字を載せるため大きく空けておく
```

## 優先度A（これだけで見違える）

### A-1. スライド〈N〉「〈スライド名〉」
〈なぜこの絵が要るのかを1行〉

```
【構図】
〈何を・どこに・どう配置するか。文章で3〜5行。
　最後に「画面の〈左／右／下〉は文字を載せるため大きく空ける」と必ず書く〉
```
保存名：`〈NN_name.png〉`

（A-2、A-3 … と必要な数だけ続ける。3〜5枚が目安）

## イラスト発注が不要なスライド

表・数字が主役のスライドは、絵を作らず余白と文字組みで整える。

| スライド | 内容 | 対応 |
|---|---|---|
| 〈N〉 | 〈内容〉 | 〈表のみ／数字を特大に／既存素材を流用 など〉 |

---

## 納品チェック

届いたPNGを確認する。

✓ 画像の中に文字・数字が入っていないか（**最も守られにくい**）
✓ 指定色以外の派手な色が入っていないか
✓ 前の画像と絵柄のトーンが揃っているか
✓ 文字を載せる予定の側が空いているか
✓ 16:9になっているか

1つでもNGなら、同じチャットで「文字が入ってしまったので消して」
「もっとシンプルに」と続けて直す。作り直すより速い。
