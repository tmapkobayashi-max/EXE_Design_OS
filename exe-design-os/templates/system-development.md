# EXE Design OS - System Development Template

Version: 1.0

---

# Purpose

This template defines the standard structure for system development proposals.

It is the default template for proposals involving system implementation, cloud migration, business improvement, application development, infrastructure modernization, and digital transformation.

Unless another template is clearly more appropriate, this template should be selected.

---

# Proposal Goal

Every proposal should help the client answer three questions.

1. Why do we need to change?

2. Why is EXE MATE the right partner?

3. What will improve after implementation?

The proposal should naturally guide the client toward a confident decision.

# Slide Objectives

## 1. Cover

Purpose

Introduce the proposal.

Deliver confidence from the first impression.

Component

Hero

---

## 2. Background & Current Situation

Purpose

Explain the client's current environment.

Clarify why change is necessary.

Component

Compare

Color

Current Situation

Sub Grey

---

## 3. Current Issues

Purpose

Visualize existing operational problems.

Avoid excessive text.

Component

Cards

Recommended

3–6 issue cards.

---

## 4. Future Vision

Purpose

Show what success looks like after implementation.

Focus on business outcomes rather than technology.

Component

Hero

Color

EXE Pink

---

## 5. Proposed Solution

Purpose

Explain how EXE solves the identified problems.

Component

Relationship

Show the relationship between:

Current Problems

↓

EXE Solution

↓

Business Value

---

## 6. System Architecture

Purpose

Visualize the system structure.

Prefer architecture diagrams over paragraphs.

Component

Relationship

Purpose

- Error Reduction
- Response Speed
- Productivity Improvement

Major numbers must use Level 1 typography.

# Proposal Writing Rules

Every slide should communicate one primary idea.

Body text should remain within two or three lines.

Prefer diagrams over paragraphs.

Use business language.

Avoid unnecessary technical terminology.

---

# AI Generation Rules

Before generating the proposal:

1. Understand the client's business.

2. Identify current problems.

3. Determine the desired future state.

4. Select this template.

5. Generate the slide sequence.

6. Select components.

7. Apply the Visual System.

8. Validate using:

06_VALIDATION_SYSTEM.md

---

# Success Criteria

A successful proposal should:

✓ Clearly explain the client's current problems.

✓ Present a realistic future vision.

✓ Demonstrate EXE MATE's value.

✓ Build trust.

✓ Make the next step obvious.

✓ Be understandable within a few minutes.

The client should finish the presentation thinking:

"This proposal is clear, practical, and I want to work with EXE MATE."
