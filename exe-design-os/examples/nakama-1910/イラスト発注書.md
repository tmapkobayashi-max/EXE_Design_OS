# 中間市「なかまの礎1910 未来レンガ」15枚 ― イラスト発注書

作成：2026-07-23
目的：既存pptx（カード・表のみで殺風景）を、イラスト主導のビジュアル資料に作り替える。
基準：`exe-design-os/docs/07_ART_DIRECTION.md`
発注先：Codex（ChatGPT有料版の画像生成）／**1チャット1画像**

---

## 使い方

1. 下の「共通指定」を1回コピーしておく。
2. 各スライドの「構図」だけを差し替えて発注する。
3. 届いたPNGを `sozai/illust/` に、指定のファイル名で保存する。
4. ファイル名を小林さんに伝えれば、pptx／HTMLに組み込む。

★ **絵柄をそろえるコツ**：1枚目で気に入った絵ができたら、
**同じチャットの続き**で2枚目以降を頼む。チャットを分けると絵柄がズレる。

---

## 共通指定（★毎回この下に貼る★）

```
【スタイル】
・細い手描きの線画に、淡い水彩の陰影を乗せた絵柄
・彩度は低く、全体はグレーと生成り色を基調にする
・色を持つのは「光る線・光る点」だけ。色は #FF6366（ピンク）のグロー
・光源は1方向のみ。強い影やグラデーションは付けない
・人物は表情を作り込まず、輪郭をシンプルに。スーツ姿

【比率】
16:9

【厳守・NG要素】
・文字、数字、単語、ロゴ、記号を画像内に一切描かない
・グラフ、チャート、データパネル、ダッシュボード風の要素を描かない
・看板、タグ、プレート、モニター画面の中身のような矩形パネルを描かない
・写真的なリアリズム、3DCG風の光沢を出さない
・指定した色以外の彩度の高い色を使わない
・画面の左側（または指定した側）は、文字を載せるため大きく空けておく
```

# 優先度A ― 先にこの5枚（これだけで見違えます）

## A-1. スライド7「画面では、どう見える？」
**最も画像不足が痛いスライド。ここが1枚あるかないかで資料の説得力が変わります。**

```
【構図】
レンガ造りの歴史的な建物（ポンプ室）を、4つの視点の変化として1枚に描いてください。
左上に上空からの俯瞰、そこから1本の光る線が右下へ向かい、
だんだん建物に近づき、最後は壁面のレンガ1個へ寄っていく流れ。
4つの通過点に小さな光る円を置く。背景は川と周囲の緑。
画面の左下は文字を載せるため大きく空ける。
```
保存名：`07_screen_flow.png`

2階はやや軽やかな造りで、企業らしい建物の影がいくつか並んでいる。

# イラスト発注が不要なスライド

以下は表・数字が主役です。イラストは作らず、余白と文字組みで整えます。

| スライド | 内容 | 対応 |
|---|---|---|
| 5 | 個人フロー（8ステップ） | ステップ図を作り直す。イラスト不要 |
| 6 | 企業フロー（9ステップ） | 同上 |
| 11 | 収支の見取り図 | 数字を特大（Level 1）で見せる。イラスト不要 |
| 13 | 運用・設置 | 既存 `sozai/設置イメージ_ポンプ室モニター.png` を流用 |
| 14 | 確認事項 | 表のみ |

スライド12「つくり方」は既存 `sozai/` のマップ画像を流用します。

# 発注チェックリスト

届いたPNGについて確認してください。

✓ 画像の中に文字・数字が入っていないか（**最も守られにくい**）
✓ ピンク以外の派手な色が入っていないか
✓ 前の画像と絵柄のトーンが揃っているか
✓ 文字を載せる予定の側が、ちゃんと空いているか
✓ 16:9になっているか

1つでもNGなら、同じチャットで「文字が入ってしまったので消して」
「もっとシンプルに」と続けて修正してください。作り直すより速いです。
